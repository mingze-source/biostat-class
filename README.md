## 各檔案簡介與結論

### 1. 生統作業0924：生活滿意度問卷分析

**簡介**：以 37 份問卷資料，用 SPSS 交叉表與 Pearson 卡方檢定（附 Fisher 精確檢定），檢視 13 個生活與心理變項（感情狀態、性別、居住地、養寵物、學樂器、運動、打電玩、秋冬情緒、自我了解、自覺可靠、對生成式 AI 的焦慮與使用經驗、每月可支配金額）是否與「是否滿意現在的生活」有關。

**結論**：只有兩個變項與生活滿意度顯著相關：
- **打電玩習慣**（χ² = 6.010，p = 0.014）：每週打電玩超過兩次者滿意比例 84.6%，不打者 45.5%。
- **自我了解程度**（χ² = 8.852，p = 0.003）：「還算認識自己」者滿意比例 90.9%，「努力了解中」者 46.7%。

其餘 11 個變項（性別、感情狀態、收入、AI 焦慮等）皆無顯著差異。樣本小，多數表格有期望次數 < 5 的格子，解讀時應參考 Fisher 精確檢定。

### 2. 生統作業1001（DM）：糖尿病組與正常組比較

**簡介**：比較 DM 組與正常組的血糖、BMI 與收縮壓，並比較男女的血糖與血壓，以 Mean ± SD 表格與 SPSS 盒鬚圖呈現。

**結論**：
- DM 組血糖（193.36 ± 12.04 vs 95.45 ± 6.28 mg/dL）與 BMI（30.68 ± 0.99 vs 23.34 ± 1.25 kg/m²）皆顯著高於正常組（p < 0.01），收縮壓也明顯較高。
- 男女之間血糖（p = 0.361）與血壓（p = 0.644）無顯著差異。

### 3. 生物統計學1001（投籃）：三組命中率比較

**簡介**：比較 Male、female、teacher 三組的 percentage（命中率），以單因子變異數分析搭配 Tukey HSD 與 Scheffé 法做事後多重比較，另比較男女的 Salary。

**結論**：在 α = 0.05 下，三組之間**均無顯著差異**（Male vs. female p = 0.494；Male vs. teacher p = 0.093；female vs. teacher p = 0.259），兩種事後檢定結論一致。Male 與 teacher 平均差 32.5，但 teacher 組僅 2 人、標準誤大，只呈邊緣趨勢。男女 Salary 亦無差異（p = 0.956）。

### 4. DM 生理代謝統計分析交接報告（.docx）

**簡介**：以 DM.xls（22 位受試者，兩組各 11 人）為資料的完整交接報告。先以 Shapiro–Wilk 與 Levene 檢定確認前提，再用 Welch t 檢定與 Mann–Whitney U 檢定雙軌驗證，並計算 Cohen's d／Hedges' g 效應量，附 Seaborn 箱型圖與 Python 重現步驟。

**結論**：組別 1（DM）在三項指標皆顯著高於組別 2，且兩組幾乎完全分離：
- 血糖：+97.91 mg/dL（95% CI 89.18–106.64），t = 23.91，p < 0.001，d = 10.19
- 收縮壓：+27.73 mmHg（95% CI 22.82–32.64），t = 11.78，p < 0.001，d = 5.02
- BMI：+7.35 kg/m²（95% CI 6.34–8.35），t = 15.32，p < 0.001，d = 6.53

血糖兩組變異數不同質（Levene p = 0.039），因此採 Welch t 檢定；無母數檢定結論相同。

### 5. 生物統計分析報告1015：無母數檢定

**簡介**：三份小樣本資料，因部分組別不符常態或變異數不同質，改用無母數檢定，並附效應量、事後檢定與交接檔（DM）。
- HER2 表現量：乳癌（BC）vs 肺腺癌（LUAD），Mann–Whitney U 檢定
- 四聯盟（NBA／MLB／NFL／WNBA）運動員年薪：Kruskal–Wallis H ＋ Dunn's test（Bonferroni 校正）
- 四種血型的身高：Kruskal–Wallis H，並以 one-way ANOVA 交叉驗證

**結論**：
- **HER2**：BC 顯著高於 LUAD（U = 71，exact p = 0.00016，r = 0.81），兩組幾乎完全分離。
- **年薪**：四組有顯著差異（H(3) = 27.61，p < 0.001，ε² = 0.71），差異來自 WNBA 顯著低於其他三個聯盟；三個男子聯盟之間無差異。WNBA 是唯一女性組，聯盟與性別互相混淆。
- **血型與身高**：無顯著差異（H(3) = 1.51，p = 0.68），ANOVA 結論一致。

### 6. 橘郡異常事件調查報告

**簡介**：針對 669 位橘郡居民的普查資料，描述患病嚴重程度、飲用水來源、死亡率與性別比例，並以卡方檢定、風險比（RR）與勝算比（OR）找出死亡的可能原因，最後與台灣烏腳病比較並提出防治建議。

**結論**：
- 整體死亡率 77.0%，患病者全數死亡。
- **飲用深井水是唯一顯著因子**：深井組死亡率 99.8%，自來水＋淺井組 8.4%（χ² = 590.987，p < 0.001；RR = 11.9；OR = 5475.2），且病情呈深井 > 淺井 > 自來水的劑量–反應關係。
- 性別（p = 0.978）與年齡（p = 0.903）與死亡無關。
- 臨床表現與台灣烏腳病（深井水砷暴露）相符，推測致病因子為深井水中的砷（尚待水質檢驗證實）。此病不會人傳人；建議立即停用深井水、檢驗水質並推動自來水。
