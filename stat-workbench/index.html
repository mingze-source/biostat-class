連接我的 AI

選擇你平常用的 AI，貼上你自己的 API 金鑰。AI 只會收到變數名稱、統計摘要與你的問題，不會收到原始資料。

常見問題

ChatGPT Plus／Gemini Advanced／SuperGrok 訂閱可以直接用嗎？不行。網站要用的是「API 金鑰」，要到各家的開發者後台另外申請；Gemini 在 Google AI Studio 有免費額度，OpenAI 與 xAI 依用量計費。

金鑰存在哪裡？只存在你這台裝置的瀏覽器裡（沒勾「記住」時，關閉分頁就會清除），不會傳到本站或其他人。請不要在公用電腦勾選「記住」。

顯示「無法連線」？部分服務不允許網頁直接呼叫，或你在 claude.ai 內開啟（那裡不允許連到外部網站）。請改用 GitHub Pages 版本，或選「自訂端點」透過 OpenRouter 等服務轉接。

圖表風格與下載

風格會立即套用到所有圖表與下載的檔案。仿軟體風格是依各軟體預設外觀調配的近似樣式，不是官方範本。自訂風格儲存在這台電腦的瀏覽器中。

樣本數規劃

在蒐集資料前估計需要多少樣本，才能以指定的檢定力偵測到預期效果。結果可用 R 或 Python 驗證。

效果量最好依據過去研究或前導研究，而不是直接套用「中效果」。

方法與軟體指南

本站整合三位統計專家對各軟體的評價：保留它們的長處，並針對它們共同的缺點設計功能。超出本站範圍的方法，這裡也告訴你該用哪個工具。

需求對照檢查
